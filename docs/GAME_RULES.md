# Правила игры TaskSwitch Arena

## Концепция
Игроки должны классифицировать символы по меняющимся правилам. Тренируется когнитивная гибкость — способность быстро переключаться между задачами.

## Правила классификации

### 1. Чётное/Нечётное (EVEN_ODD)
- **Символы:** цифры 0-9
- **Вопрос:** "Чётное?"
- **Правильный ответ:**
  - 0, 2, 4, 6, 8 → ДА (чётное)
  - 1, 3, 5, 7, 9 → НЕТ (нечётное)

### 2. Гласная/Согласная (VOWEL_CONSONANT)
- **Символы:** латинские буквы a-z
- **Вопрос:** "Гласная?"
- **Правильный ответ:**
  - a, e, i, o, u → ДА (гласная)
  - Остальные → НЕТ (согласная)

### 3. Кратно 3 (MULTIPLE_OF_THREE)
- **Символы:** числа 0-99
- **Вопрос:** "Кратно 3?"
- **Правильный ответ:**
  - 0, 3, 6, 9, ... → ДА
  - Остальные → НЕТ

## Система очков

### Индивидуальные очки
Базовые очки: 10
Бонус скорости: max(0, 15 - floor(время_мс / 100))
Максимум: 25 очков (ответ < 500мс)

## Игровой процесс

1. **Лобби:** создание/присоединение к комнате
2. **Распределение:** Snake Draft + боты до 6 игроков
3. **Раунды:** 15 раундов по 5-15 секунд
4. **Правила меняются каждый раунд**
5. **Побеждает команда с наибольшим счётом**

## Алгоритм Snake Draft
Паттерн: A, B, B, A, A, B
Игроки сортируются по рейтингу
1-й → А, 2-й → B, 3-й → B, 4-й → A, 5-й → A, 6-й → B

| Лёгкий  | 60%      | 1000-2500ms |
| Средний | 75%      | 600-1800ms |

## Рейтинговая система (Elo)
Expected_A = 1 / (1 + 10^((Rating_B - Rating_A) / 400))
New_Rating = Old_Rating + K × (Score - Expected)
K = 32
